# quscope.github.io

Website of the QuScope project: https://quscope.github.io

Single-file static site (no build step): `index.html` holds the markup, CSS and vanilla JS (theme toggle saved
to localStorage, pipeline tabs, copy buttons); `assets/favicon.svg` is the icon. Retro-editorial design with
light (parchment) and dark (midnight vinyl) themes. GitHub Pages serves the `main` branch. Preview locally with
`python -m http.server` in this folder.

- Code: https://github.com/QuScope/QuScope
- Docs: https://quscope.readthedocs.io
