Quantum circuits for electron microscopy.

QuScope rebuilds transmission electron microscopy image formation as quantum circuits. The electron wavefunction is amplitude-encoded on qubits, and every optical element (specimen phase grating, Fresnel propagation, objective lens) is a diagonal unitary between quantum Fourier transforms, validated against classical references.

By Sean D. Lam & Roberto dos Reis · Northwestern University

The method

The microscope, rewritten as a circuit.

One circuit per image (CTEM) or per probe position (STEM); slices repeat for thick specimens.

01 //Encoding

Wavefunction on qubits

An N×N wavefield lives on 2 log2N qubits through amplitude encoding.

02 //Circuits

Optics as diagonal gates

Phase gratings, Fresnel propagation and the lens are diagonal unitaries between quantum Fourier transforms.

03 //Verified

Validated

Noise-free circuits reproduce the classical reference implementations to unit fidelity.

04 //Backends

Simulator to hardware

Qiskit Aer statevector and shots, noise models, and IBM Quantum devices through one backend manager.

Side A · Track 1

CTEM (weak phase object)

  • Phase grating eiσV applied to the encoded plane wave.
  • QFT, the contrast transfer function of the objective lens, inverse QFT.
  • Bright-field image from the measured register.

Side A · Track 2

CTEM multislice

  • The specimen is cut into slices along the beam.
  • Alternating phase gratings and Fresnel propagators between QFTs.
  • Thick, multiply scattering specimens.
quantum_multislice_circuit

Side B · Track 1

STEM (single slice)

  • A focused probe prepared at each scan position.
  • HAADF, ADF, ABF, BF and iDPC detector channels.
  • One quantum circuit per probe position.
quantum_stem

Side B · Track 2

STEM multislice

  • The probe state passes through the full multislice circuit.
  • The same detector channels as single-slice STEM.
  • A multislice circuit for every scan position.

Admit one · Get started

Install QuScope in one line.

pip install quscope

Latest fixes (0.2.1): git clone -b v0.2.x https://github.com/QuScope/QuScope

from quscope.quantum_ctem import QuantumCTEMCircuit, QuantumCTEMParameters
import numpy as np

params = QuantumCTEMParameters(acceleration_voltage=200e3, grid_size=8,
                               pixel_size=0.5, defocus=-659.7, cs=1.3)
result = QuantumCTEMCircuit(params).simulate(np.random.rand(8, 8) * 100)
print(result["intensity"].shape)   # (8, 8)
